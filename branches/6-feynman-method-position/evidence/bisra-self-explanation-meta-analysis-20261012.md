# 来源摘要

同行评审期刊论文的搜索摘要描述了一项自我解释诱发研究元分析，比较提示自我解释与学习结果。摘要表明部分情境下自我解释有益，但不能据此确定所有研究的效应、异质性或偏倚情况。

# 支持主张的原文要点

- 搜索摘要提及研究综合了自我解释提示与学习结果的比较。
- 此卡只支持“自我解释在一些受研究情境中可能有益”的有限主张，不记录未从摘要核实的数值效应。

# 适用范围

自我解释提示的实验研究综合；具体学习任务、样本与测量需查原文。

# 局限

当前仅检索结果摘要，未核对全文、纳入标准、效应量、异质性、发表偏倚及调节变量；该来源研究的是自我解释，不是对命名的“费曼技巧”四步流程的直接验证。

# 可能冲突

其他候选研究显示效果可能随任务与提示设计变化；需全文核对后判断，当前不视为冲突已解决。

# 与当前 branch 的关系

为费曼式“用自己的话解释”作为学习活动提供间接机制证据；不证明简单化表达本身充分，也不证明解释能力等于实践能力或迁移能力。
