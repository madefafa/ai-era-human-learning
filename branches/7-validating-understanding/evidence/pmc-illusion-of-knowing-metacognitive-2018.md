# 来源摘要

PMC 检索到“元认知监控中的知道感错觉”一文。摘要指出该错觉可能出现在各类元认知判断中，且在前瞻性判断中更明显。检索结果中另有一条 ResearchGate 同题长标题记录，视为同一研究的镜像/聚合入口，不重复计为独立研究。

# 支持主张的原文要点

- 摘要线索：illusion of knowing 可发生于所有类型元认知判断，但在 prospective judgments（前瞻性判断）中更明显。
- 与“熟悉感/流畅性可导致高估掌握”的核心问题方向一致。

# 实际获取层级

仅取得摘要片段。样本、任务材料、判断类型、测量方法、效应方向与大小、统计细节均未核对。ResearchGate 入口与 PMC 全文未做镜像独立性判断，仅登记为同一研究线索。

# 适用范围

适合作为“熟悉感可能误导掌握判断”的方向性线索；不能据以声称某一特定干预能可靠校准所有学习者。

# 局限

只拿到摘要级信息；未确认该 PMC 文章是否即为研究论文原文、是否同行评议、样本与效应值。研究发表于 2018 年，与后续元认知校准证据的关系需另核。

# 可能冲突

部分研究线索提示流畅性并不总是影响元认知判断（见检索记录 Query 2 中其他 PMC 条目），说明熟悉感的作用可能随任务、线索类型与人群变化；本卡不足以裁决。

# 与当前 branch 的关系

直接支持“熟悉感不等于掌握”的核心命题，但仅作为摘要级候选证据，提醒不可把主观流畅、熟悉或“感觉会了”当作已掌握判断。
