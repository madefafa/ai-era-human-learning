# Issue 11 跨学科学习 — draft（awaiting-confirmation）

> 状态：`draft / awaiting-confirmation`；`confirmed=false`。本文只是候选简报，未经用户确认不得视为最终结论。全部来源卡片均为摘要级、未全文核验。

## 1. 问题与目标

- 研究问题：AI 是连接学科的工具，还是制造表面类比的机器？
- 目标：研究共享概念、映射关系、问题边界、跨域类比有效性与验证，以及工程/科学/社会场景中的跨学科协作案例。
- 本次只基于一次授权 webgo batch（4 查询×itemnums=15、categories=science,general）与 10 张摘要级候选卡，组织候选节点骨架；不预设 AI 一定能连接学科。
- **明确边界：跨学科学习 ≠ 各学科知识相加。**（模型推论，见 §2）

## 2. 跨学科入口（事实 / 候选证据 / 推论分层）

- 事实（工具返回）：batch `exit_code=0`，4/4 success，返回 226/207/200/173（合计 806 候选），均 `target_reached`、1 页；失败引擎未报告。
- 候选证据：跨学科整合被讨论为需要“概念消歧”“边界概念/边界对象”“共享问题与多视角”（卡 01、02、03、08）。
- 推论（待验证）：跨学科入口可组织为“共享概念 → 映射关系 → 问题边界 → 验证机制”的工作假设，而非单一动作。
- 推论（待验证）：若整合只是把各学科术语并列而不做概念消歧，则更接近“知识相加”而非真正的跨学科理解（卡 01 支持“消歧是关键环节”的候选说法，但未核验其测量与效果）。
- 建议：后续把“是否完成概念消歧/是否建立共享边界对象”作为区分“真整合 vs 知识相加”的候选判据，并逐卡核验。

## 3. 共享概念与映射

- 候选证据：边界概念可先被定义、再构建为“边界对象”式的概念框架、最后作为边界对象使用；该三阶段被称支持沟通、协作与整合（卡 02）。
- 候选证据：边界对象与知识整合、创新管理相关，且其作用依情境（渐进式 vs 激进式创新）而异（卡 03，摘要被截断，方向未核验）。
- 候选证据：协作式概念图（含个人准备阶段）被用于支持跨学科思维与知识整合（卡 04，`contextual`，结果未核验）。
- 推论（待验证）：共享概念是“映射关系”的载体；映射不是术语字典式对照，而是把一域的关系结构在另一域重建。
- 未知：共享概念/映射的操作化度量、成功判定与失败模式均未确定。

## 4. 类比验证（结构与表面）

- 候选证据：问题解决/迁移研究区分“深层结构”与“表面特征”，并讨论二者交互（卡 05）。
- 候选证据：跨域类比被定义为捕捉“表面不同、深层结构相似”的关系映射；个别研究把跨域类比能力与创造力、脑功能连接相联系（卡 06，仅为相关性线索，`confidence=low`）。
- 推论（待验证）：“有解释力的类比”倾向保持结构/机制一致并可产生可证伪预测；“仅语言相似的类比”多在表面特征上相似而结构不对应。
- 推论（待验证）：类比验证应检查（a）结构对应、（b）机制一致性、（c）能否给出可检验预测、（d）反例/边界条件；这些判据的权重与适用范围尚未确定。
- 未知：上述判据的可操作性、可靠性与跨领域可迁移性均未研究。
- 与 Issue 8 边界：Issue 8 已涉及结构映射/类比；本 branch 只在“跨域 + 验证判据 + AI 角色”角度独立处理，不合并结论。

## 5. 案例选择标准（工程 / 科学 / 社会）

- 候选证据：工程与社会科学跨学科框架强调“先对齐概念设计（what/why），再展开方法”（卡 07）。
- 候选证据：团队科学把跨学科界定为“多学科调查者围绕共同问题、从不同视角研究同一问题”（卡 08）。
- 推论（待验证）：案例选择标准可包含——是否存在真实共同问题、是否有多学科视角的必要性、是否有可观察的整合/产出、是否有可验证的结果、是否记录了边界/失败。
- 建议：候选案例库优先纳入同时描述“协作过程 + 可验证结果”的来源，而非仅宣传跨学科价值的推广材料。
- 未知：本次未获得具体可核验的跨学科协作案例全文，案例库尚未建立。

## 6. AI 连接器边界

- 候选证据（风险面）：AI 幻觉源于多层技术脆弱性，机制与人类错误信息不同，需要分层风险框架（卡 09）。
- 候选证据（缓解面）：让模型自审的“验证链”被提出用于降低幻觉（卡 10，预印本，效果未核验）。
- 推论（待验证）：AI 可充当“跨学科连接候选生成器/假设源”，但连接正确性需要外部验证；同一模型自审可能继承自身偏见，不能作为唯一验证。
- 推论（待验证）：AI 的高置信表达形式与其正确性不挂钩（卡 09 线索），因此跨域类比尤其需要独立核验。
- 条件式判断（不预设）：AI 是否“更适合连接学科”仍属未知；现有材料只能支持“AI 生成的跨域连接同时携带价值与风险”这一候选陈述。
- 建议：把“AI 生成跨域类比 → 结构校验 → 反例搜索 → 外部证据核验”作为候选验证流程，而非直接采信。
