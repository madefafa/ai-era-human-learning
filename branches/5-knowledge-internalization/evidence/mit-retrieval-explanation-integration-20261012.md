# 来源摘要

MIT Teaching + Learning Lab 的搜索摘要提到，让学习者回答概念问题并解释正确答案，可结合主动提取和解释活动。

# 支持主张的原文要点

搜索摘要级线索：活动被描述为同时涉及 recently learned concepts 的 retrieval practice 与 explanatory processing。尚未全文核对其适用条件和结果指标。

# 适用范围

可作为“独立回忆后解释”这一观察任务的教学资源级候选依据，适用于课堂或自学练习设计。

# 局限与冲突

机构教学页面不是对单一实验的完整报告；不能从摘要推断解释活动必然带来长期保持、迁移或因果理解，也不能确认与单纯提取相比的增量效果。
