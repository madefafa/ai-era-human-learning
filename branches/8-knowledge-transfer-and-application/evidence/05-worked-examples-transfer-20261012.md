# 来源摘要

搜索摘要称该研究比较 worked examples 与学习/迁移测试，并报告 worked examples 在保持与迁移测试上有利，同时可能降低认知负荷和逐步挑战。

# 摘要级要点

- 支持将 worked examples 作为迁移训练的候选组成，而非只让学习者直接盲解。
- 不保留样本、效应量、统计显著性或因果强度；这些均需全文核验。

# 适用条件

初学者、步骤结构较清晰或认知负荷较高的任务可能更适合先研究解法再逐步撤除支架；需要安排后续独立生成和新题测试。

# 局限与冲突

搜索摘要不足以判断学习者先验知识、任务复杂度、示例数量和延迟测验。worked examples 不能自动保证远迁移，过度被动观看也可能不足以形成可检索结构。
