# 来源摘要

搜索摘要明确区分 surface features 与 structural features，并指出在类比相关性被指出后，结构特征对使用类比的影响更大。

# 支持主张的摘要级要点

- 支持“结构映射不等于表面相似”的候选机制。
- 摘要未提供完整任务条件，不能推断学习者会自发发现结构关系。

# 适用条件

适用于设计迁移练习时要求学习者标注关系、约束、因果角色和解法，而不是只匹配名词、场景或外观。

# 局限与冲突

“相关性已被指出”是重要条件；若没有提示，表面特征可能仍然主导检索。摘要不足以支持跨学科普遍性或具体教学效果。

# 当前 branch 关系

作为结构相似/表面相似的核心候选卡，并用于 AI 生成题的人工审查维度。
