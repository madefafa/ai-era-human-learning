# 来源摘要

搜索结果要点声称自动化程度提高会把责任和责难从用户转向AI系统，并称用户控制和信息处理下降可解释这种效应。

# 支持主张的原文要点

- `Higher automation shifts responsibility and blame from users to AI systems`。
- `Reduced user control and information processing explain automation effects`。

# 适用范围

AI辅助决策中的责任归因、控制感和信息加工；可用于责任稀释风险。

# 局限与冲突

- 未核验样本、任务、实验条件、测量、统计结果、效应量或因果识别。
- “归因转移”不等于法律或道德责任实际上已经转移。
- 不同风险和专业场景可能出现相反模式。

# 与当前branch的关系

支持区分心理责难归因、组织问责和规范责任，并要求责任与控制、信息、能力相匹配。
