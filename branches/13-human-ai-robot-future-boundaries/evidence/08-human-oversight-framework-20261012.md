# 来源摘要
摘要将高风险决策中的 AI 使用描述为同时面对技术、安全和规范挑战，并提出有效人类监督框架的议题。

# Snippet 级支持要点
支持区分监督者的真实判断能力、信息权限、接管能力和制度责任，而非只检查是否有人签字。

# 局限与冲突
未核验框架的实证验证；不证明人类监督总能控制系统，也不证明自动化不可治理。

# 与本 branch 的关系
连接监督者、责任归属、制度能力和未知风险。
